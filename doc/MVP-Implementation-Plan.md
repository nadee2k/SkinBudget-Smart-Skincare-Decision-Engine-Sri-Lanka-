# SkinBudget MVP Implementation Plan (Real-World)

## Phase 1: Foundation (current)
- Production-aware FastAPI service with typed request validation.
- Environment-driven recommendation scoring weights.
- Version-controlled environment template (`.env.example`).

## Phase 2: Productization
- Authentication and saved routines.
- Admin product ingestion workflow.
- Price snapshots and retailer links.

## Phase 3: Decision Intelligence
- Constraint-based budget optimizer.
- Concern-specific contraindication rules.
- Explainable recommendation reasons.

## Phase 4: Launch Readiness
- Monitoring and error tracking.
- Automated data quality checks.
- Analytics events for onboarding and routine conversion.
